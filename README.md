## 📖 О проекте

**CraftVerse Launcher** — это лаунчер для запуска Minecraft: Java Edition на Android-устройствах. Интерфейс построен на Jetpack Compose, запуск игры выполняется через встроенную Java-среду.

Главная особенность — **встроенный редактор скинов**: рисуйте скин прямо на 3D-модели персонажа и сразу видьте его в игре, даже в офлайн-режиме.

## ✨ Возможности

### Лаунчер
- 🎮 Запуск Minecraft: Java Edition на Android
- 👤 Офлайн-аккаунты и вход через **Microsoft**
- 📦 Установка и управление версиями игры
- ⚙️ Настройка памяти (RAM), аргументов JVM и параметров запуска
- 🎨 Современный интерфейс на Jetpack Compose, новая иконка и логотип

### 🖌️ Редактор скинов
Открывается кнопкой **«Скин»** (иконка футболки) в левом боковом меню.

| Функция | Описание |
|---|---|
| **3D-модель** | Вращение, масштабирование и рисование прямо по модели персонажа |
| **2D-развёртка** | Классическая развёртка текстуры 64×64 с попиксельным редактированием |
| **Инструменты** | Кисть, ластик, заливка, пипетка |
| **Зеркальное рисование** | Симметричное рисование левой и правой стороны |
| **Сетка** | Пиксельная сетка для точной работы |
| **Undo / Redo** | Отмена и повтор действий |
| **Слои** | Основной слой и внешний слой (шляпа, куртка, рукава, штанины) |
| **Модели** | Стив (классические руки 4 px) и Алекс (тонкие руки 3 px) |
| **Палитра** | Выбор цвета через HSV и ввод HEX-кода, недавние цвета |
| **Шаблоны** | Готовые заготовки скинов для старта |
| **Импорт / экспорт** | Загрузка и сохранение скина в формате PNG |
| **Черновик** | Автосохранение незавершённой работы |
| **«В игре»** | Переключатель применения скина при запуске игры |

### 🌐 Скин в игре для офлайн-аккаунтов
Обычно офлайн-аккаунт в Minecraft получает стандартный скин. CraftVerse решает это так:

1. При запуске игры лаунчер поднимает **локальный сервер скинов** (совместимый с Yggdrasil API) на `127.0.0.1`.
2. Игра запускается с Java-агентом [authlib-injector](https://github.com/yushijinhun/authlib-injector), который перенаправляет запросы профиля и текстур на локальный сервер.
3. Minecraft загружает ваш скин из редактора — он виден в инвентаре, от третьего лица и в одиночной игре.

Скин хранится во внутренней памяти приложения:
```
files/custom_skin/skin.png   — текстура 64×64
files/custom_skin/skin.json  — метаданные (модель Стив/Алекс, флаг «В игре»)
```

## 📥 Установка

1. Скачайте последний `CraftVerseLauncher-*.apk` со страницы [Releases](../../releases/latest).
2. Разрешите установку из неизвестных источников для браузера или файлового менеджера.
3. Откройте APK и подтвердите установку.
4. Запустите CraftVerse, добавьте аккаунт и установите нужную версию игры.

> ⚠️ **Конфликт подписи.** Если раньше была установлена версия с другим ключом подписи, Android выдаст ошибку «Приложение не установлено». Удалите старую версию (предварительно сохраните миры и скины) и установите заново.

## 🎨 Редактор скинов

1. Нажмите **«Скин»** в левом меню.
2. Выберите модель — **Стив** или **Алекс**.
3. Рисуйте на 3D-модели или на 2D-развёртке. Одним пальцем — рисование, двумя — вращение и масштаб (в 3D).
4. Переключайте **основной / внешний** слой для деталей вроде шлема или куртки.
5. Включите **«В игре»** и нажмите **«Сохранить»**.
6. Запустите игру с офлайн-аккаунтом — скин уже на персонаже.

Готовый скин можно **экспортировать в PNG** и загрузить на официальный сайт Minecraft для лицензионного аккаунта.

## 🗂️ Структура проекта

```
craftverse-launcher/
├── app/                         # декомпилированный APK (apktool)
│   ├── AndroidManifest.xml      # + SkinEditorActivity
│   ├── smali/                   # исходный код лаунчера (classes.dex)
│   │   └── …                    # патчи: пункт меню «Скин», запуск JVM с агентом
│   ├── res/                     # ресурсы, adaptive-иконка
│   └── assets/
│       ├── branding/logo.png    # логотип в главном меню
│       └── components/
│           └── authlib-injector/
│               └── authlib-injector-1.2.5.jar
├── skinsrc/                     # Java-исходники редактора → classes2.dex
│   └── com/craftverse/skin/
│       ├── SkinEditorActivity.java   # экран редактора
│       ├── Skin3DView.java           # 3D-модель и рисование по ней
│       ├── SkinMapView.java          # 2D-развёртка 64×64
│       ├── ColorPicker.java          # палитра HSV / HEX
│       ├── SkinStore.java            # сохранение, черновик, импорт/экспорт
│       └── SkinServer.java           # локальный Yggdrasil-сервер + patchArgs
├── build.sh                     # скрипт сборки
└── README.md
```

> Названия отдельных файлов в `skinsrc/` могут отличаться — ориентируйтесь на фактическое содержимое репозитория.

**Как редактор связан с лаунчером:**
- В боковое меню (NavigationRail) добавлен 5-й пункт, открывающий `SkinEditorActivity`.
- Перед стартом игры вызов `JvmLauncher.startJvm` проходит через `SkinServer.patchArgs`, который запускает локальный сервер и добавляет аргумент
  `-javaagent:authlib-injector-1.2.5.jar=http://127.0.0.1:<порт>`.

## 🔧 Сборка из исходников

### Зависимости
- JDK 17+
- [apktool](https://apktool.org/) 2.10+
- Android SDK Build-Tools (`d8`, `zipalign`, `apksigner`)
- `android.jar` нужной платформы (для компиляции `skinsrc`)

### Шаги

```bash
# 1. Собрать ресурсы и smali
apktool b app -o build/unsigned.apk

# 2. Скомпилировать редактор скинов в classes2.dex
javac --release 8 -cp "$ANDROID_HOME/platforms/android-34/android.jar" \
      -d build/classes $(find skinsrc -name '*.java')
d8 --min-api 26 --lib "$ANDROID_HOME/platforms/android-34/android.jar" \
   --output build/dex $(find build/classes -name '*.class')
mv build/dex/classes.dex build/classes2.dex

# 3. Добавить classes2.dex в APK
(cd build && zip -j unsigned.apk classes2.dex)

# 4. Выровнять и подписать
zipalign -p -f 4 build/unsigned.apk build/aligned.apk
apksigner sign --ks your-release.jks --out build/CraftVerseLauncher.apk build/aligned.apk
apksigner verify build/CraftVerseLauncher.apk
```

Или одной командой:
```bash
./build.sh
```

> 🔐 **Никогда не публикуйте keystore и пароли от него.** Добавьте `*.jks`, `*.keystore` и `keystore.properties` в `.gitignore`, а для CI используйте секреты (GitHub Actions Secrets).

## ❓ FAQ

**Скин не отображается в игре.**
Проверьте, что в редакторе включён переключатель **«В игре»**, скин сохранён, и вы запускаете игру с **офлайн-аккаунтом**.

**Почему на Microsoft-аккаунте другой скин?**
Для лицензионных аккаунтов используется официальный скин с серверов Mojang. Экспортируйте скин в PNG и загрузите его в профиль на minecraft.net.

**Другие игроки на сервере не видят мой скин.**
Локальный сервер скинов работает только на вашем устройстве. Скин виден вам в одиночной игре; на сетевых серверах — только если сервер сам поддерживает authlib-injector / вашу систему скинов.

**«Приложение не установлено» при обновлении.**
Скорее всего, у установленной версии другой ключ подписи — удалите её и поставьте новую.

## ⚠️ Известные ограничения
- Скин из редактора применяется только для офлайн-аккаунтов.
- Поддерживаются скины формата 64×64 (старые 64×32 конвертируются при импорте).
- Плащи (capes) пока не поддерживаются.
- Производительность игры зависит от GPU и объёма ОЗУ устройства.
